# Design skills

Emil Kowalski's design-engineering skills, copied from https://github.com/emilkowalski/skills (commit 64eb3de, MIT licence, see LICENSE-emilkowalski-skills). The web-relevant subset is kept here so every session on this repo can load them. Used on this site: animate, choreograph, mobile-native, emil-design-eng.

Also installed: Anthropic `frontend-design` (https://github.com/anthropics/skills, Apache 2.0, see frontend-design/LICENSE.txt) and Impeccable by Paul Bakaus (https://github.com/pbakaus/impeccable, Apache 2.0, see impeccable/LICENSE). Used for v2: frontend-design, impeccable (concept roll, craft floor, detector).
